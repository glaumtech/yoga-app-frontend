## Common Questions & Answers

### Q: Can multiple judges score the same participant?
**A:** Yes, multiple judges can score the same participant. Scores are averaged for final calculation.

### Q: How are scores calculated?
**A:** Individual asana scores are averaged across judges, then summed for category totals, and finally summed for grand total.

### Q: Can participants register for multiple events?
**A:** Yes, participants can register for multiple events through the events list.

### Q: Is the system secure?
**A:** Yes, we use role-based access control, secure authentication tokens, and encrypted data transmission.

### Q: Can we export data?
**A:** Yes, scores and participant data can be exported (if feature is implemented).

### Q: What happens if a judge makes a mistake?
**A:** Admins can view all scores and judges can update scores before final submission.
